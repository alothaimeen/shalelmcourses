# إضافة قبول طالبات شموخ العلم

[![Moodle Plugin CI](https://github.com/alothaimeen/shalelmcourses/actions/workflows/ci.yml/badge.svg)](https://github.com/alothaimeen/shalelmcourses/actions/workflows/ci.yml)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](COPYING.txt)

`local_shomokh_admissions` إضافة مستقلة لـMoodle 4.5 تدير التسجيل في الدبلوم
التأسيسي والمسارين التخصصيين، مع إبقاء منطق الدخول والهوية في
`local_qlogin_shomokh`.

## الحصول على الإضافة

نزّل حزمة `local_shomokh_admissions-*.zip` من صفحة
[الإصدارات](https://github.com/alothaimeen/shalelmcourses/releases)، ثم ثبّتها من:

**إدارة الموقع ← الإضافات ← تثبيت الإضافات**

يوضع المصدر يدويًا، عند الحاجة، في `local/shomokh_admissions`. لا ترفع ملفات
البيئة أو بيانات الطالبات أو الشهادات إلى المستودع أو إلى بلاغات المشكلات.

## ما الذي تنفذه؟

- تتعرف على طالبات الدفعة الثالثة من التحاقاتهن الحالية دون طلب جديد.
- تعتبر الطالبة مؤهلة داخليًا للتخصصي عندما تبلغ نتيجة المستوى المحسوبة في
  Moodle القيمة المحددة للاجتياز (مثل «إكمال الدورات = 1»).
- تطلب شهادة خاصة فقط عند الاعتماد على مؤهل خارجي، ثم تعرضها لموظفة مخولة.
- تطلب اختيار الحديث أو التفسير قبل المراجعة.
- عند رفض المؤهل تعرض الدفعة الرابعة، ولا تلحق الطالبة بها دون موافقتها الصريحة.
- تلحق الطالبة بالمقررات وبـCohort اختياري بطريقة قابلة لإعادة المحاولة ولا
  تكرر الالتحاقات الموجودة.
- تعرض رابط تيليجرام فقط بعد ثبوت الاستحقاق.
- توفر سجل تدقيق، وسياسة احتفاظ للشهادات، وMoodle Privacy API.

## متطلبات التشغيل

- Moodle `4.5.x`.
- PHP `8.1` أو إصدار مدعوم من Moodle 4.5.
- تفعيل Cron.
- وجود طريقة إلحاق يدوي `manual` فعالة في كل مقرر سيُربط ببرنامج.
- وجود بند نتيجة محسوب في Moodle يثبت اجتياز المستوى التأسيسي كاملًا.

## الأمان الافتراضي

بعد التثبيت تكون الإضافة والبرامج الأربعة معطلة. لا تظهر واجهة تقديم للطالبات
قبل أن يربط المسؤول المقررات والمجموعات والروابط، ويجتاز كل برنامج فحص الجاهزية،
ثم يفعله صراحة. ملفات الشهادات تحفظ في File API الخاص بـMoodle ولا تُتاح إلا
لصاحبة الطلب وموظفة تملك صلاحية المراجعة.

يمكن تشغيل «صفحة القبول المغلق» بشكل مستقل قبل اكتمال الإعداد. هذا الوضع يعرض
التعريف وموعد الإعلان لاحقًا فقط، ولا يقبل طلبات أو شهادات ولا يشغّل التعرف
الآلي أو إلحاق الطالبات.

## الإعداد المختصر

1. افتح: إدارة الموقع ← الإضافات ← قبول طالبات شموخ العلم.
2. في الدفعة الثالثة اختر بند «نتيجة الدفعة الثالثة-المستوى الأول — إكمال
   الدورات» واجعل قيمة الاجتياز `1`.
3. اربط الدفعة الرابعة ومساري الحديث والتفسير بمقررات الوجهة المناسبة.
4. اختر Cohort عند الحاجة، وضع رابط تيليجرام لكل وجهة.
5. افتح التسجيل للدفعة الرابعة والمسارين التخصصيين فقط.
6. فعّل التعرف من الالتحاقات الحالية للدفعة الثالثة فقط.
7. يمكن إظهار صفحة القبول المغلق أثناء الإعداد دون تشغيل العمليات.
8. عالج كل تحذيرات الجاهزية، ثم فعّل الإضافة العامة عند فتح القبول فعليًا.

راجع [DEPLOYMENT_AR.md](DEPLOYMENT_AR.md) لخطوات النشر والتراجع الآمنة.
وللمساهمة أو الإبلاغ عن عيب راجع [CONTRIBUTING.md](CONTRIBUTING.md)، أما
الثغرات الأمنية فتُبلغ وفق [SECURITY.md](SECURITY.md).

## الاختبارات

يتضمن الإصدار 23 اختبار PHPUnit تغطي 74 تحققًا، منها الأهلية الداخلية، الشهادة
الخارجية، قرار الموظفة، موافقة البديل، الإلحاق المتكرر، Cohort، إعادة المحاولة،
التعرف المرحلي، والتصدير والحذف وفق الخصوصية، وعزل وضع العرض المغلق عن العمليات.
